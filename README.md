# Code VIP

Code VIP یک اپ فارسی‌اول و **Local-first** برای دسترسی موبایلی به ابزارهای کدنویسی است. اپ چت، پروژه‌ها، نشست‌های ترمینال و تنظیمات را روی دستگاه ذخیره می‌کند و برای ارتباط مدل‌ها از اینترنت خود کاربر استفاده می‌کند.

## قابلیت‌های نسخه فعلی

- رابط فارسی و راست‌به‌چپ برای چت کدنویسی
- کاتالوگ مدل‌های API و کاتالوگ جداگانه ابزارهای CLI
- ترمینال محلی داخل اپ برای نمایش نشست‌ها و دستورهای آماده
- اتصال اختیاری به Termux برای اجرای دستورها در محیط Android
- انتخاب ابزارهای Claude Code، Codex CLI، Gemini CLI، OpenCode، Kilo CLI و Grok Build
- نمایش صادقانه وضعیت هر ابزار: قابل‌آزمایش با Termux، آزمایشی در Android یا اتصال ابری/API
- ذخیره و ادامه گفتگوها با AsyncStorage
- ذخیره تاریخچه ترمینال روی دستگاه
- جست‌وجو، حذف و مدیریت گفتگوها
- ذخیره کلید API در Android Keystore / iOS Keychain
- پشتیبانی از APIهای OpenAI-compatible و Anthropic Messages API
- انتخاب فایل از پنجره رسمی فایل سیستم و پیوست‌کردن کد
- بدون درخواست دسترسی گسترده به حافظه؛ فقط فایل انتخاب‌شده توسط کاربر خوانده می‌شود
- workflow گیت‌هاب برای ساخت APK مستقل Release

## معنی «محلی» در این نسخه

اپ روی گوشی نصب می‌شود و فایل‌ها، چت‌ها و تاریخچه را روی همان گوشی نگه می‌دارد. برای اجرای CLIهای واقعی، Android باید محیط سازگار مانند Termux داشته باشد. Code VIP دستور نصب، ورود و اجرای هر ابزار را نشان می‌دهد و می‌تواند Termux را باز کند؛ اما به‌دلیل نبود پشتیبانی رسمی Android برای بعضی CLIها، هیچ ابزار را به‌صورت جعلی «از قبل داخل APK نصب‌شده» معرفی نمی‌کند.

برای اجرای پایدارتر، کاربر می‌تواند Termux را از منبع رسمی F-Droid نصب کند. دستورهای نمایش‌داده‌شده باید در محیط Termux اجرا و با حساب خود کاربر احراز هویت شوند. Code VIP کلید مشترک یا حساب مشترک ارائه‌دهندگان را در APK قرار نمی‌دهد.

## ابزارهای CLI

| ابزار | وضعیت در اپ | دستور نمونه |
|---|---|---|
| Claude Code | قابل آزمایش با Termux؛ Android رسمی نیست | `claude` |
| Codex CLI | آزمایشی در Android | `codex` |
| Gemini CLI | آزمایشی در Android | `gemini` |
| OpenCode | مناسب‌تر برای آزمایش با Termux | `opencode` |
| Kilo CLI | آزمایشی در Android | `kilo` |
| Grok Build | آزمایشی در Android | `grok` |

## بارگذاری فایل

دکمه سنجاق کنار کادر پیام، انتخاب‌گر رسمی فایل دستگاه را باز می‌کند. کاربر می‌تواند حداکثر پنج فایل را انتخاب کند. فایل‌های کدی کوچک برای چت خوانده می‌شوند و سایر فایل‌ها به‌عنوان پیوست ثبت می‌شوند.

## اجرای توسعه‌ای

```bash
pnpm install
pnpm dev
```

## بررسی کیفیت

```bash
pnpm check
pnpm lint
pnpm test
npx expo export --platform web --output-dir /tmp/code-vip-export
```

## ساخت APK

Workflow گیت‌هاب در `.github/workflows/build-apk.yml` با push روی شاخه `main` یا اجرای دستی، APK Release می‌سازد و به‌عنوان artifact با نام `code-vip-apk` ذخیره می‌کند.

```bash
npx expo prebuild --platform android --no-install --non-interactive
cd android
./gradlew assembleRelease --no-daemon
```

## محدودیت‌های مهم

Claude Code، Codex CLI، Gemini CLI، OpenCode، Kilo و Grok مدل قابل‌دانلود برای جاسازی در APK نیستند. آن‌ها به runtime، احراز هویت و مجوز ارائه‌دهنده نیاز دارند. Code VIP رابط محلی، کاتالوگ، ترمینال و دستورهای آماده را فراهم می‌کند؛ اجرای واقعی هر CLI به سازگاری Android/Termux و حساب خود کاربر وابسته است.
